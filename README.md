*TPA Game by MJ24-2*

### What is RogueHH?
RogueHH is a turn-based, roguelike-themed game where the player goes through a series of dungeon floors and defeats the enemies to advance to the next floor.

### Features
- Aesthetic low poly 3D graphics
- Atmospheric music and SFX
- Stat upgrades and leveling system
- Click-based grid movement
- Turn-based combat with skills
- Challenging boss floor
- Save system to keep track of progress
